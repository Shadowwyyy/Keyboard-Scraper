# Mechanical Keyboard Parts Explorer

A comprehensive toolkit for exploring, comparing, and building mechanical keyboards. This project allows you to gather data from hundreds of keyboard websites and analyze it to make informed decisions about your next keyboard purchase or DIY build.

## Overview

The Mechanical Keyboard Parts Explorer consists of two main components:

1. **Keyboard Scraper**: Collects data on keyboard parts from various websites
2. **Keyboard Analyzer**: Helps you explore, filter, compare, and visualize the collected data

With these tools, you can:
- Browse a vast selection of keyboard parts from multiple vendors
- Compare prices and features across different websites
- Find the best deals within your budget
- Get recommendations for complete keyboard builds
- Identify compatible components for your specific needs
- Visualize market trends and price distributions
- Save your favorite parts for future reference

## Files in this Project

- `keyboard_scraper.py`: Script that scrapes keyboard parts data from multiple websites
- `keyboard_analyzer_v2.py`: Advanced tool for analyzing and exploring the scraped data
- `keyboard_parts.csv`: Database of scraped keyboard parts (generated by the scraper)
- `keyboard_vendors.json`: List of keyboard vendors to scrape (generated on first run)
- `keyboard_favorites.json`: Your saved favorite parts (generated when you add favorites)
- `requirements.txt`: Python package dependencies
- Various PNG files: Visualizations created by the analyzer (generated during analysis)

## Setup Instructions

1. Make sure you have Python 3.7+ installed
2. Install the required libraries:

```
pip install -r requirements.txt
```

3. Download all project files to the same directory

## Using the Scraper

The keyboard scraper collects data from popular mechanical keyboard vendors. To run it:

```
python keyboard_scraper.py
```

The scraper will:
- Attempt to collect data from multiple keyboard vendors
- Categorize products automatically (kits, PCBs, cases, switches, keycaps, etc.)
- Save the data to a CSV file named `keyboard_parts.csv`
- Add dummy data if not enough real data can be collected

You can customize the scraper by editing these parameters in the script:
- `num_vendors`: Number of websites to scrape (default: 5)
- `max_products_per_vendor`: Maximum products to collect per site (default: 20)
- `add_dummy_data`: Whether to include dummy data for testing (default: True)

## Using the Analyzer

After running the scraper, you can analyze the data with:

```
python keyboard_analyzer_v2.py
```

The analyzer provides a comprehensive menu-driven interface with these capabilities:

### Basic Analysis
- View statistics about the collected parts
- Plot distributions by category, price, and source
- Compare parts across different sources

### Finding Parts
- Search by category (kit, PCB, case, etc.)
- Filter by price range
- Search by keyword
- List all parts with various sorting options

### Building Your Keyboard
- Generate recommendations based on your budget
- Get a complete keyboard build suggestion within your budget
- Find compatible parts for a specific component

### Managing Favorites
- Save interesting parts to your favorites list
- View and manage your saved favorites
- Export your favorites to a CSV file

### Data Export
- Export filtered results for external analysis
- Save visualizations as PNG files

## Example Workflows

### Finding the Perfect Kit for Your Budget
1. Run `keyboard_analyzer_v2.py`
2. Choose option 6 (Find parts by category and price)
3. Enter "kit" as the category
4. Set your budget range
5. Review the results and open URLs for more details

### Building a Custom Keyboard
1. Run `keyboard_analyzer_v2.py`
2. Choose option 13 (Build custom keyboard within budget)
3. Enter your total budget
4. The analyzer will suggest a complete set of compatible parts

### Comparing Similar Components
1. Run `keyboard_analyzer_v2.py`
2. Choose option 8 (Find parts by keyword)
3. Enter a specific keyword (e.g., "PBT keycaps")
4. Note the IDs of interesting parts
5. Use option 10 (Compare parts) to see them side-by-side

## Categories
The system recognizes these keyboard part categories:
- `kit`: Complete keyboard kits (case + PCB + plate)
- `pcb`: Printed circuit boards
- `case`: Keyboard cases
- `plate`: Mounting plates
- `switch`: Keyboard switches
- `keycap`: Keycap sets
- `stabilizer`: Key stabilizers
- `lube`: Lubricants for switches and stabilizers
- `foam`: Sound dampening materials
- `cable`: Custom keyboard cables
- `accessory`: Other accessories like switch pullers, wrist rests, etc.

## Notes

- The scraper respects websites by using appropriate delays between requests
- Some websites may block scraping attempts, resulting in missing data
- The dummy data ensures you can test the analyzer even if scraping fails
- The analyzer creates visualization PNG files in the working directory
- Your favorites are saved between sessions in the JSON file

## Troubleshooting

If you encounter any issues:

1. **No data available**: Make sure the scraper has generated the `keyboard_parts.csv` file
2. **Import errors**: Verify all required packages are installed using `pip install -r requirements.txt`
3. **Scraping failures**: Try reducing the number of vendors or increasing the delay between requests
4. **Visualization errors**: Make sure `matplotlib` and `seaborn` are correctly installed
